# 🎲 Dice Duel <a name="about-project"></a>

**Dice Duel** is a fun and simple two-player game where each player takes turns rolling a dice to accumulate points. After each roll, players can either "Hold" to save their score or risk rolling again to earn more points. But beware! Rolling 1 resets the points for that turn. The first player to reach the target score (e.g., 50 or 100) wins the game.
